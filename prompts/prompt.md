ฉันต้องการให้คุณทำงานกับ Repository GitHub ชื่อ:

abbyy-vantage-knowledge

โปรเจกต์นี้เป็น Knowledge Repository สำหรับ ABBYY Vantage และ OCR Sale Order ของบริษัท โดยมีข้อมูลเกี่ยวกับ:

- ABBYY Vantage
- OCR และ Document Classification
- JavaScript Advanced Script Rule
- Use Case จากการใช้งานจริง
- SAP/RPA Integration
- Field Name, Field Type และ Data Mapping
- ปัญหาจาก PRD และแนวทางแก้ไข
- การออกแบบ Agent ให้เข้าใจประเภทเอกสาร

กรุณาอ่านไฟล์ AGENTS.md ก่อนเริ่มงาน และปฏิบัติตามกฎในไฟล์นั้นอย่างเคร่งครัด

หลักการสำคัญ:

1. ยึด ABBYY Official Documentation เป็นแหล่งอ้างอิงหลัก
2. แยกข้อมูลเป็น ABBYY OFFICIAL, VERIFIED REAL PROJECT และ INFERENCE
3. ห้ามอ้างว่าสิ่งใดใช้งานได้จริง หากไม่มีหลักฐานหรือผลทดสอบ
4. ก่อนแก้ไขไฟล์ ให้ตรวจสอบ Repository และเอกสารเดิมก่อน
5. ห้ามเขียนทับข้อมูลเดิมโดยไม่ตรวจสอบ
6. หากไม่แน่ใจเกี่ยวกับ ABBYY Runtime, Field Path, Context API หรือ Data Type ให้แจ้งว่าเป็นสิ่งที่ต้องทดสอบ
7. หากมีการแก้ไข Code ต้องแก้เอกสาร Use Case ให้สอดคล้องกัน
8. ต้องตรวจสอบ Syntax, Test Case, Git Diff และสถานะ Remote ก่อนสรุป
9. หากทำงานกับ Git ต้องรวมไฟล์ที่เกี่ยวข้องไว้ใน PR เดียว
10. รายงานเฉพาะสถานะที่ตรวจสอบแล้วจริง

ก่อนเริ่มงาน ให้ตอบกลับ 3 ส่วน:

- คุณเข้าใจโปรเจกต์นี้อย่างไร
- คุณจะตรวจสอบไฟล์และสถานะใดก่อน
- มีข้อมูลใดที่จำเป็นต้องถามฉันก่อนลงมือหรือไม่
